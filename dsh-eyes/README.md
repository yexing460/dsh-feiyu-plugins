# dsh-eyes

给 DSH 上的 AI 一双**持续**的眼睛。

单次截图 DSH 的 `computer` 工具本来就会。这个补的是“持续”：后台定时拍一张，留着最近一段时间的帧，之后可以随时倒回去看“刚才屏幕上发生了什么”。

默认**每 3 秒一张、能回看最近 10 分钟**（约 200 帧）。

> 早期版本默认是“2 秒一张、留 60 张”，也就是只能回看两分钟——看个视频片段就翻不回去了。
> 2026-11-02 改了：配置项换成按**分钟**算，因为人关心的是“能回看多久”，不是“留几张”。

## 为什么

AI 没有时间感。它看不到“用户刚才那十分钟在干什么”，只能看到两条消息之间的空白。有了这串帧，至少能回放。

## 用法

工具名 `eyes`，四个动作：

| 动作 | 说明 |
| --- | --- |
| `start` | 开始后台截屏 |
| `stop` | 停止（会等它收尾，把最后几张留下） |
| `status` | 现在有几张、最后一张是什么时候 |
| `recent` | 拿最近 N 张的路径（配合 `read_image` 看） |

## 配置

```yaml
- id: eyes
  name: dsh-eyes
  config:
    interval: 3        # 每隔几秒截一张（太密会拖慢机器）
    keepMinutes: 10    # 能回看最近多久（分钟）——人关心的是这个
    # keep: 200        # 旧写法：直接指定留几张；给了 keepMinutes 就不看它
    # dir: ''          # 留空则用系统临时目录下的 fy-eyes
```

想回看更久就调 `keepMinutes`：`30` 分钟大约 600 帧，磁盘占用一两百 MB。
磁盘紧就调 `interval`：`5` 秒一张能省 40%。

## 前置条件

- **Windows**（用 `System.Windows.Forms` + `System.Drawing` 截屏）
- 截图脚本 `scripts/capture.ps1` 随包携带，不需要另外准备
- 多显示器时**只截主屏**
